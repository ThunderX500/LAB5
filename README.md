## Installation

1. Clone the repository and move into the project folder:

   ```bash
   git clone https://github.com/ThunderX500/LAB5
   cd LAB5
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```
.

- Start the development server:

  ```bash
  npm start
  ```

- Run the unit tests (Karma + Jasmine):

  ```bash
  npm test
  ```
